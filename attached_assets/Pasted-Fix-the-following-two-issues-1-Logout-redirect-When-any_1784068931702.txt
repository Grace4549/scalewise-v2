Fix the following two issues:
1. Logout redirect:
When any user (client, expert, or admin) logs out from any page or dashboard, immediately redirect them to the homepage after clearing their session. Do not leave them on the page they were viewing while logged in. The redirect must happen instantly after logout is confirmed, before any protected page content could be visible. Apply this consistently across all logout buttons and session expiry events sitewide.
2. Redesign the expert availability input from individual slot selection to range-based input:
Replace the current week grid where experts click individual 1-hour boxes one at a time with a smarter, range-based availability input system. The new system should work as follows:
The expert sees their weekly calendar with each day listed. For each day, instead of clicking individual slots, they can add one or more time ranges by selecting a start time and end time from dropdowns or a time picker. For example, they can set Monday as 9:00 AM to 1:00 PM and 3:00 PM to 6:00 PM as two separate ranges on the same day. They can add multiple ranges per day using an Add Range button, and remove any range with a Remove button next to it.
Once the expert saves their availability, the system automatically splits each time range into consecutive 1-hour slots in the database. So a range of 9:00 AM to 1:00 PM automatically becomes four separate bookable slots: 9:00 AM, 10:00 AM, 11:00 AM, and 12:00 PM. These slots are what clients see and book on the expert's public profile, displayed as individual time options, not as ranges.
The expert dashboard should still show a visual summary of their availability for the current week after saving, so they can confirm what they set. This summary view can use the grid layout already built, but it should be read-only and auto-populated from the ranges they entered, not manually clickable.
Also keep the existing features we already specified: the Available for new bookings on/off toggle, the long-term recurring availability option, and the weekly reminder emails on Friday, Saturday, and Sunday if availability has not been set for the upcoming week.
Do not change how availability appears to clients on the expert's public profile. Clients should still see individual bookable 1-hour time slots to choose from, exactly as before. Only the expert's input method changes, from individual slot clicking to range-based entry.
